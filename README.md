# Viewpoint - Building Fix

Патч для **Project Viewpoint** (Project Zomboid B42), який робить будинки від першої особи цілісними: дахи, фронтони, стіни, вікна й стелі.

Встановлення: скопіюй теку `ViewpointRoof` у `%UserProfile%\Zomboid\mods`, увімкни її разом із **Viewpoint** і **ZombieBuddy** та підтвердь мод у вікні ZombieBuddy при першому запуску.
